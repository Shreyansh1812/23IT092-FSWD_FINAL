# Full-Stack Web Development Final Project

## Project Overview

This project is a **Full-Stack Employee Management System** designed to streamline the process of managing employee data. It includes features such as adding, editing, deleting, and viewing employee details, along with user authentication and role-based access control.

The project is divided into two main parts:
1. **Frontend**: Built using React, TailwindCSS, and Vite for a modern, responsive, and user-friendly interface.
2. **Backend**: Developed with Node.js, Express, and MongoDB to handle API requests, authentication, and database operations.

---

## Project Aim

The primary goal of this project was to create a robust and scalable employee management system that allows:
- **Admins** to manage employee records efficiently.
- **Users** to securely log in and access their data.
- **Seamless integration** between the frontend and backend for a smooth user experience.

---

## Achievements So Far

### Frontend
- **React-based UI**: A responsive and interactive interface for managing employees.
- **Authentication**: Login and registration pages with JWT-based authentication.
- **Employee Management**: Features to add, edit, delete, and search employees.
- **Dashboard**: A centralized view for managing employee data.
- **Protected Routes**: Ensures only authenticated users can access certain pages.
- **TailwindCSS**: Used for styling to ensure a modern and consistent design.

### Backend
- **RESTful API**: Built with Express.js to handle CRUD operations for employees.
- **MongoDB Integration**: A NoSQL database for storing employee data securely.
- **Authentication**: JWT-based authentication with access and refresh tokens.
- **File Uploads**: Support for uploading employee profile pictures using Multer.
- **Error Handling**: Comprehensive error handling for better debugging and user feedback.

---

## Features Implemented
1. **User Authentication**:
    - Secure login and registration.
    - Token-based authentication with refresh token support.

2. **Employee Management**:
    - Add, edit, delete, and view employee details.
    - Upload and display employee profile pictures.
    - Search functionality for quick access to employee records.

3. **Role-Based Access**:
    - Protected routes to ensure only authorized users can access certain features.

4. **Responsive Design**:
    - Fully responsive UI for desktop and mobile devices.

## Technologies Used

### Frontend
- **React**: For building the user interface.
- **React Router**: For navigation and routing.
- **TailwindCSS**: For styling.
- **Vite**: For fast development and build processes.

### Backend
- **Node.js**: For server-side scripting.
- **Express.js**: For building the RESTful API.
- **MongoDB**: For database management.
- **Multer**: For handling file uploads.
- **JWT**: For secure authentication.
